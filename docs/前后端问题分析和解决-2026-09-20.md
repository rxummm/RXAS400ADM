## 二、详细分析与修复

### 2.1 ECharts 图表闪烁（useECharts composable）

**现象**：从作业依赖图（`/job/dependency`）或拓扑图（`/topology`）切换到其他 tab 再切回来，图表闪烁（先显示空白再渲染）。

**根因**：`RxSkeleton` 组件在 `loading` 状态切换时会销毁/重建 DOM 元素。`useECharts` 在 `onMounted` 时绑定 `elRef.value` 指向的 DOM 节点，但 DOM 重建后原节点消失，新节点不在 echarts 实例的绑定中。

**修复**：`useECharts.ts` 中增加 `watch(elRef)` 监听 DOM 元素变化：

```typescript
watch(elRef, (newEl, oldEl) => {
  if (newEl && newEl !== oldEl && chartInstance) {
    chartInstance.dispose()
    chartInstance = null
    init()
  }
})
```

**文件**：`frontend/src/composables/useECharts.ts`

**前端修复**：

### 2.7 用户配置分页

**现象**：用户配置页（`/as400/user-profiles`）分页不工作，始终显示第一页数据。

**根因**：API 响应格式为 `{code: 0, message: "ok", data: {total: N, records: [...]}}`，前端 `.then(data => ...)` 接收到的是外层包装器，`data.records` 为 `undefined`。

**后端修复**：
- `UserProfileManagementController.java`：增加 `current/size/keyword` 参数，返回 `PageResult<UserProfileListRow>`
- `IUserProfileService.java`：`listUserProfiles(int current, int size, String keyword)` 带关键字搜索
- `UserProfileServiceImpl.java`：使用 `As400PaginationHelper.queryPaged()` + LIKE 关键字过滤

**前端修复**：
- `api/userProfileManagement.ts`：`fetchUserProfileList` 返回 `PageResult<UserProfileListRow>`，参数改为 `{ current, size, keyword, serverId }`
- `userProfiles/index.vue`：load 方法正确解包 `.then(res => res.data ?? res)`，增加 `AppPagination`

**关键修复**（响应解包逻辑）：
```typescript
const load = async () => {
  const res = await fetchUserProfileList({ current: pagination.currentPage, size: pagination.pageSize, keyword: searchKeyword, serverId: currentServerId })
  const data = res.data ?? res   // 解包 {code,message,data} 包装器
  profiles.value = data.records ?? []
  pagination.total = data.total ?? 0
}
```

**文件**：
- `backend/rxas400adm-as400/src/main/java/com/rxas400adm/as400/controller/UserProfileManagementController.java`
- `backend/rxas400adm-as400/src/main/java/com/rxas400adm/as400/service/UserProfileServiceImpl.java`
- `frontend/src/api/userProfileManagement.ts`
- `frontend/src/views/as400/userProfiles/index.vue`
