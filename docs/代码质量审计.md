## 二、审计结论（无需修复/已达标）

- **前端 i18n 纪律良好**：全量扫描 `.vue` 模板文本节点与 `ElMessage/ElMessageBox` 调用，**无硬编码中文**（均为 `$t()` / i18n 引用；少数 `Excel (.xlsx)`、`Port`、`MSGW` 等专业词保留原文属合理）。
- **后端权限码纪律良好**：除已标注暂缓的模块外，写操作均有 `@PreAuthorize` + `@OperateLog`。
- **未使用后端接口**：`/as400/systems` CRUD 与 `/command` 目前无前端 UI（assets 页只读），API 保留并经 AS400_MANAGE 加固——属**预留接口**而非死代码；`/source/**`、`/compile`、`/deployments` 随发布/源代码模块暂缓保留。

## 四、审计方法备忘

- 前端死代码：`grep -oE "export (const|function) [a-zA-Z0-9_]+" src/api/*.ts` 提取导出 → 全 src 反查引用（**注意函数名含数字时 `[a-zA-Z]+` 会截断，必须用 `[a-zA-Z0-9_]+`**）。
- 前端硬编码：模板文本 `>[中文][^<]*<` 且行内无 `$t`；脚本内 `ElMessage.xx('中文'`。
- 后端 SQL 注入：检索字符串拼接 SQL 且无转义工具方法（本项目统一 `sq()`）。
- 后端低效：`selectList(null).stream().limit` 模式。
