## 一、功能增强（待实施）

### E1: 告警未处理自动升级

**功能描述**：告警产生后，若指定时间内未处理，自动通知管理员

**配置参数**：
```yaml
rxas400:
  alert:
    upgrade:
      enabled: false  # 功能开关，默认关闭
      check-interval-minutes: 5  # 检查间隔（分钟）
      upgrade-after-minutes: 30  # 未处理多久后升级（分钟）
      notify-role: ADMIN  # 升级通知的角色
      notify-channels:  # 通知渠道
        - WEBHOOK
        - NOTIFICATION  # 站内通知
```

**实现要点**：
- 定时任务定期检查未处理告警（`RX_ALERT_EVENT.STATUS != 'RESOLVED'`）
- 超过配置时间未处理 → 发送站内通知给指定角色
- 支持通过管理界面动态开关

**数据库变更**：
```sql
-- 告警事件表添加升级时间字段
ALTER TABLE RX_ALERT_EVENT ADD COLUMN UPGRADE_TIME TIMESTAMP;
ALTER TABLE RX_ALERT_EVENT ADD COLUMN UPGRADE_NOTIFIED SMALLINT DEFAULT 0;
```

**预估工时**：4-6小时

| 启停子系统 | SUBSYSTEM_MANAGE | 启动/停止子系统 |
| 删除作业调度 | SCHEDULE_DELETE | 删除调度配置 |
| 删除告警规则 | ALERT_DELETE | 删除告警规则 |


### E3: 操作审计日志增强

**功能描述**：记录操作时间、命令、数据表、操作人等关键信息

**审计日志字段**：
```sql
CREATE TABLE RX_AUDIT_LOG (
    ID BIGINT PRIMARY KEY,
    USER_NAME VARCHAR(50),        -- 操作人
    ACTION VARCHAR(50),            -- 操作类型（CREATE/UPDATE/DELETE/EXECUTE）
    MODULE VARCHAR(50),            -- 模块（JOB/IFS/SYSTEM/...）
    TARGET VARCHAR(200),           -- 操作对象（作业名、文件路径、表名）
    IP VARCHAR(255),               -- 操作IP
    DETAIL TEXT,                   -- 操作详情（命令、参数、影响行数）
    RESULT VARCHAR(20),            -- 操作结果（SUCCESS/FAIL）
    COST_MS BIGINT,                -- 执行耗时（毫秒）
    CREATED_TIME TIMESTAMP         -- 操作时间
);
```

**增强@OperateLog注解**：
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface OperateLog {
    String module() default "";
    String operation() default "";
    boolean recordDetail() default true;  // 是否记录详情
    boolean recordTarget() default true;  // 是否记录操作对象
}
```

**预估工时**：4-6小时

### E5: 快捷键支持

**功能描述**：键盘快捷键提升操作效率

**快捷键规划**：
| 快捷键 | 功能 |
|---|---|
| `Ctrl+K` | 打开命令面板 |
| `Ctrl+/` | 打开快捷键帮助 |
| `1-9` | 快速切换服务器 |
| `R` | 刷新当前页面 |
| `Esc` | 关闭弹窗 |

**实现方式**：
```typescript
// composables/useShortcuts.ts
export function useShortcuts() {
  const shortcuts = {
    'ctrl+k': () => openCommandPalette(),
    'ctrl+/': () => showShortcutsHelp(),
    'escape': () => closeAllDialogs()
  }
  
  onMounted(() => {
    Object.entries(shortcuts).forEach(([key, handler]) => {
      hotkeys(key, handler)
    })
  })
  
  onUnmounted(() => {
    hotkeys.unbindAll()
  })
}
```

**预估工时**：2-4小时

```vue
</el-button>
```

**后端实现**：
```java
@PostMapping("/jobs/batch-end")
@PreAuthorize("hasAuthority('JOB_END')")
public ApiResponse<Void> batchEndJobs(@RequestBody List<JobParam> jobs) {
    jobs.forEach(job -> jobService.endJob(job.getJobName(), job.getJobUser(), job.getJobNumber()));
    return ApiResponse.success();
}
```

## 五、系统稳定性

### S1: 优雅停机

**功能描述**：等待进行中的操作完成后再关闭应用

**配置**：
```yaml
server:
  shutdown: graceful

spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s
```

**价值**：避免正在执行的CL命令被中断，导致IBM i端状态异常

**预估工时**：0.5小时（仅配置）
