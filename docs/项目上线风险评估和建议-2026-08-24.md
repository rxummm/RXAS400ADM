### 5.3 数据库迁移：MySQL → DB2 for i（RXADMIN Library）

> **核心变更**：项目自身表（用户/菜单/权限/配置/日历/文档/审计等）从 MySQL 8 迁移到 US400CND 的 **RXADMIN** Library，使用 DB2 for i 原生存储。不再需要 MySQL。

#### 5.3.1 迁移范围

| 项 | 说明 |
|---|---|
| 目标 Library | `RXADMIN`（在 US400CND 上创建） |
| 表数量 | ~25 张项目表（rx_user/rx_role/rx_menu/rx_permission/rx_config/rx_audit_log/rx_notification/...） |
| 数据来源 | 当前 MySQL 中的数据（需一次性导出导入） |
| 不涉及的表 | AS400 系统表（QSYS2 视图）、源码/作业等本就在 AS400 上的数据 |

#### 5.3.2 代码变更清单

| 变更项 | 当前（MySQL） | 目标（DB2 for i） | 影响范围 |
|--------|-------------|-------------------|----------|
| JDBC 驱动 | `com.mysql.cj.jdbc.Driver` | `com.ibm.as400.access.AS400JDBCDriver` 或 DB2 JDBC | `pom.xml` + `application.yml` |
| JDBC URL | `jdbc:mysql://localhost:3306/rxas400adm` | `jdbc:as400://localhost/RXADMIN` | `application.yml` + `application-prod.yml` |
| Flyway 依赖 | `flyway-mysql` | `flyway-database-db2` 或移除 Flyway（改用手动建表） | `pom.xml` |
| DDL 语法 | `AUTO_INCREMENT` / `ENGINE=InnoDB` / `DEFAULT CHARSET=utf8mb4` | `GENERATED ALWAYS AS IDENTITY` / 无引擎声明 / DB2 collation | V1~V44 全部迁移文件 |
| 数据类型 | `TINYINT` / `TEXT` / `DATETIME` | `SMALLINT` / `CLOB` / `TIMESTAMP` | 迁移文件 + Entity 注解 |
| SQL 函数 | `NOW()` / `IFNULL()` / `GROUP_CONCAT()` | `CURRENT_TIMESTAMP` / `COALESCE()` / `LISTAGG()` | MyBatis Plus 自动处理，但自定义 SQL 需检查 |
| HikariCP | `maximum-pool-size: 20` | 同上（DB2 连接池参数兼容） | 无需改动 |

#### 5.3.3 Flyway 迁移策略

**方案 A（推荐）：新建 DB2 版迁移文件**
- 保留 V1~V44 作为 MySQL 历史记录
- 新建 V45+ 为 DB2 for i 版本（使用 `db2` profile）
- 通过 Spring Profile 切换数据源：`dev` → MySQL，`prod` → DB2

**方案 B：手动建表**
- 移除 Flyway 依赖
- 手动在 RXADMIN Library 中建表（通过 ACS 或 PASE 命令行）
- 适合表结构稳定后不再频繁变更的场景

#### 5.3.4 DB2 for i 建表示例

```sql
-- 在 RXADMIN Library 中创建用户表（DB2 for i 语法）
CREATE TABLE RXADMIN.RX_USER (
    ID BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    USERNAME VARCHAR(50) NOT NULL,
    PASSWORD VARCHAR(200) NOT NULL,
    EMAIL VARCHAR(100),
    STATUS VARCHAR(20) DEFAULT 'ACTIVE',
    LOGIN_SOURCE VARCHAR(20) DEFAULT 'PLATFORM',
    CREATED_BY VARCHAR(50),
    CREATED_TIME TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UPDATED_TIME TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 创建索引
CREATE INDEX RXADMIN.IDX_USER_USERNAME ON RXADMIN.RX_USER (USERNAME);
```

#### 5.3.5 数据迁移步骤

1. 从 MySQL 导出数据：`mysqldump --no-create-info rxas400adm > data.sql`
2. 转换语法（AUTO_INCREMENT → IDENTITY、NOW() → CURRENT_TIMESTAMP 等）
3. 在 RXADMIN Library 中执行建表 DDL
4. 导入数据（通过 ACS 上传 CSV 或 PASE 命令行）
5. 验证数据一致性

#### 5.3.6 风险与注意事项

| 风险 | 等级 | 说明 |
|------|------|------|
| DDL 语法不兼容 | 🔴 高 | V1~V44 全部迁移文件使用 MySQL 语法，需逐条改写为 DB2 for i |
| MyBatis Plus 兼容性 | 🟡 中 | MyBatis Plus 支持 DB2，但 `LIMIT/OFFSET` 语法不同（DB2 用 `FETCH FIRST n ROWS ONLY`） |
| 自增主键 | 🟡 中 | MySQL `AUTO_INCREMENT` → DB2 `GENERATED ALWAYS AS IDENTITY`，Entity `@TableId(type = IdType.AUTO)` 需验证 |
| 数据类型映射 | 🟡 中 | `TINYINT` → `SMALLINT`、`TEXT` → `CLOB`、`DATETIME` → `TIMESTAMP` |
| 中文排序 | 🟢 低 | DB2 for i 支持 `COLLATE SYSTEM_CN` 中文排序 |
| 连接字符串 | 🟢 低 | JTOpen JDBC URL 格式：`jdbc:as400://host/library` |

### 5.4 环境变量配置

在 US400CND 上创建部署脚本（如 `/QOpenSys/rxas400/start.sh`）：

```bash
#!/bin/sh
# RXAS400ADM 启动脚本（US400CND）

# JDK 路径（项目目录内的 OpenJDK 17）
JAVA_HOME=/QOpenSys/rxas400/jdk17
PATH=$JAVA_HOME/bin:$PATH

# 项目目录
APP_HOME=/QOpenSys/rxas400
JAR=$APP_HOME/rxas400adm-app-1.0.0-SNAPSHOT.jar

# 环境变量（生产必须设置）
export RXAS400_JWT_SECRET=<≥32字节随机值，如 openssl rand -base64 32>
export RXAS400_CRYPTO_KEY=<AES-256 密钥，如 openssl rand -base64 32>
export RXAS400_IBMI_HOST=localhost
export RXAS400_IBMI_USER=<IBM i 用户>
export RXAS400_IBMI_PASSWORD=<IBM i 密码>
export RXAS400_IFS_DOC_ROOT=/QOpenSys/rxas400/document
export RXAS400_PORT=8080
export RXAS400_LOG_DIR=$APP_HOME/logs

# 启动（后台，指定 JVM 内存参数）
nohup java -Xms256m -Xmx1024m \
  -jar $JAR \
  --spring.profiles.active=prod \
  --spring.datasource.url="jdbc:mysql://$RXAS400_DB_HOST:$RXAS400_DB_PORT/$RXAS400_DB_NAME?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true" \
  > $RXAS400_LOG_DIR/startup.log 2>&1 &

echo $! > $APP_HOME/rxas400adm.pid
echo "rxas400adm started, PID=$(cat $APP_HOME/rxas400adm.pid)"
```

**IBM i 部署优先关注**：
1. **数据库迁移是最大工作量**：V1~V44 迁移文件需从 MySQL 语法改写为 DB2 for i 语法（AUTO_INCREMENT → GENERATED ALWAYS AS IDENTITY 等）
2. OpenJDK 17 必须是 **IBM i / ppc64 原生版本**（非 x86/Linux 移植版）
3. RXADMIN Library 需提前创建（`CRTLIB RXADMIN`）并授权运行用户
4. IFS 目录权限需提前配置（运行用户对 `/QOpenSys/rxas400/` 有读写权限）
5. JTOpen 本机连接（localhost:8470）无需网络配置，但需确认 DRDA 服务已启动
6. 数据迁移：从 MySQL 导出 → 语法转换 → 导入 RXADMIN
7. admin 默认密码 admin123 首次登录后必须修改
