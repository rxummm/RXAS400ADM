# RXAS400ADM 功能增强分析

**分析日期**：2026-09-11  
**分析角度**：AS400 ERP 业务 + 管理维度  
**目标**：识别可增强/优化的模块和功能，按收益和实现难度排序

---

## 一、当前项目能力概览

| 模块 | 已有能力 | 缺失能力 |
|------|----------|----------|
| AS400 服务器管理 | 多服务器、健康监控、CL 执行 | 无 |
| BPCS/ERP 业务 | 订单、库存、运单、协同、模拟 | 采购、财务、成本 |
| 运维功能 | 作业管理、消息队列、文档、IFS | 设备管理、变更管理 |
| 监控告警 | 性能监控、告警规则、巡检 | 容量规划、趋势预测 |
| 系统管理 | 用户、角色、权限、审批 | 数据权限、合规审计 |

| 指标 | 数据来源 | 计算逻辑 |

| 营业收入 | BPCS 订单 | SUM(orderAmount) WHERE status='COMPLETED' |

- 数据：复用 `MetricMapper`、`AlertEventMapper`、`AS400Client` BPCS SQL
- 权限码：`EXECUTIVE_DASHBOARD`（V100 迁移）
- i18n：V100 迁移种子（中英双语）

#### 2. 采购订单管理（PO Management） ✅ 已完成

**业务价值**：采购进度可视化，减少手工跟踪

| 功能 | 说明 |
|------|------|
| PO 列表 | 分页查询、状态筛选、关键词搜索 |
| PO 详情 | 订单行、发运状态、发票匹配 |

**已实现功能**：
- **PO 列表**：分页查询、状态筛选、多条件搜索、金额格式化

## 六、立即实施：Executive Dashboard 设计

### 6.1 后端设计

```java
// ExecutiveDashboardController.java
@RestController
@RequestMapping("/api/v1/dashboard/executive")
@PreAuthorize("hasAuthority('EXECUTIVE_DASHBOARD')")
@RequiredArgsConstructor
public class ExecutiveDashboardController {
    
    private final ExecutiveDashboardService dashboardService;
    
    @GetMapping("/summary")
    @Operation(summary = "高管仪表盘汇总数据")
    public ApiResponse<ExecutiveSummaryVO> getSummary() {
        return ApiResponse.success(dashboardService.getSummary());
    }
    
    @GetMapping("/trend")
    @Operation(summary = "关键指标趋势")
    public ApiResponse<List<TrendPointVO>> getTrend(
            @RequestParam String metric,
            @RequestParam(defaultValue = "30") int days) {
        return ApiResponse.success(dashboardService.getTrend(metric, days));
    }
}
```

```java
// ExecutiveSummaryVO.java
public record ExecutiveSummaryVO(
    BigDecimal revenue,           // 营业收入
    BigDecimal revenueGrowth,     // 收入增长率
    Integer totalOrders,          // 订单总数
    BigDecimal orderFulfillmentRate, // 订单履约率
    BigDecimal inventoryTurnover, // 库存周转率
    BigDecimal customerSatisfaction, // 客户满意度
    BigDecimal equipmentUptime,   // 设备可用率
    Integer activeAlerts,         // 活跃告警数
    List<TopProductVO> topProducts, // 热销产品 TOP10
    List<TopCustomerVO> topCustomers // 大客户 TOP10
) {}
```
