## 二、组件化与 Bundle 体积关系

**结论：组件化不能直接减少 JS bundle，但能显著减少源码行数。**

| 维度 | 影响 | 说明 |
|------|------|------|
| JS Bundle | ❌ 不减少 | Element Plus 已按需引入（tree-shake），封装不改变引入量 |
| 源码行数 | ✅ 减少 30-40% | 42 个表格页 × 平均 50 行重复模板 ≈ 2100 行可消除 |
| 维护成本 | ✅ 大幅降低 | 改一处 = 改 42 处 |
| 新人上手 | ✅ 显著改善 | 学会 AppTable = 学会所有表格页 |

**真正能减 bundle 的操作：**
- ECharts 拆分为独立 chunk（已有 echarts-*.js，可进一步 lazy load）
- i18n 按路由懒加载（当前 2000+ key 全量打包）
- unplugin-vue-components 已生效（Element Plus 按需引入 ✅）

## 三、运维系统标准差距分析

参照 Grafana / Datadog / Zabbix / Ansible Tower 等主流运维平台 UI 标准：

### 🔴 高优先级差距

**1. 响应式断点缺失（NOC 环境刚需）**
- 当前：固定侧边栏宽度，无媒体查询
- 运维标准：需要适配 1920px+（NOC 大屏）、1440px（标准显示器）、1024px（笔记本）
- NOC 通常有 4K/超宽屏，需要表格密度自适应
- 运维人员经常在笔记本上排查问题，需要紧凑模式

**2. 键盘导航不完整**
- 当前：仅 3 个快捷键（Ctrl+B/D/R）
- 运维标准：需要完整键盘操作（↑↓导航表格、Enter 编辑、Esc 关闭、/ 搜索）
- 运维人员每天操作 8+ 小时，鼠标疲劳是真实问题

**3. 实时数据状态指示器**
- 当前：WebSocket 连接无 UI 状态
- 运维标准：需要连接状态指示（绿/黄/红）、数据新鲜度标记、自动重连提示
- 监控系统的核心体验：用户需要知道「数据是否实时」

### 🟡 中优先级差距

**4. 批量操作支持**
- 当前：仅单行操作
- 运维标准：需要多选 + 批量操作（批量结束、批量启用/禁用规则）

**5. 表格密度控制**
- 当前：固定 size="small"
- 运维标准：需要 Compact/Default/Comfortable 三档切换

**6. 状态颜色标准化**
- 当前：状态用 el-tag 随意配色
- 运维标准：需要统一语义色（绿=正常、黄=警告、红=严重、灰=未知）

**7. 高对比度主题（无障碍合规）**
- 当前：亮/暗两套主题
- 运维标准：WCAG 2.1 AA 合规，需要高对比度模式

### 🟢 低优先级但值得做

**8. 空态引导**：场景化空态（首次使用引导、无数据引导、权限不足引导）

**9. 右键菜单**：表格行右键菜单（快速编辑、复制、删除）

**10. 导出功能**：统一导出（CSV/PDF/打印）

## 六、优化实施记录

### 2026-08-20 实施

#### ✅ Phase 1 完成

**AppTable 组件** — 封装 el-table + AppPagination + loading + 空态 + 列设置
- 统一表格骨架：loading 状态、空态插槽、分页吸底
- 支持列显隐配置、排序、筛选
- 响应式密度自适应（Compact/Default/Comfortable）

**ConfirmAction 组件** — 封装 ElMessageBox.confirm
- 统一确认弹窗样式
- 支持权限检查（v-if / disabled）
- loading 状态防止重复提交

**StatusBadge 组件** — 语义色映射
- 标准化状态颜色（green=healthy, yellow=warning, red=critical, gray=unknown）
- 支持 dot/text/icon 三种展示模式

#### ✅ Phase 2 完成

**响应式断点** — 1920px+ / 1440px / 1024px
- 表格密度自适应：大屏 Compact、标准 Default、笔记本 Comfortable
- 侧边栏自动折叠
- 搜索栏响应式换行

**键盘导航** — 完整键盘操作
- ↑↓ 导航表格行
- Enter 编辑/查看详情
- Esc 关闭弹窗/抽屉
- / 聚焦搜索框
- ? 显示快捷键帮助

**ConnectionStatus 指示器** — WebSocket 状态
- 绿/黄/红连接状态
- 数据新鲜度标记（Last updated: 3s ago）
- 自动重连提示

**BulkActions 批量操作** — 多选支持
- 表格复选框
- 批量操作工具栏
- 全选/取消全选

#### ✅ Phase 3 完成

**HighContrastTheme** — WCAG 2.1 AA
- 高对比度配色方案
- 增强焦点指示器
- 改善文字可读性

**ContextMenu 右键菜单** — 表格行操作
- 右键显示操作菜单
- 支持快捷操作（编辑/删除/复制）

**ExportDialog 导出功能** — 统一导出
- CSV 导出
- 打印预览
- 自定义导出列

**EmptyState 空态引导** — 场景化
- 首次使用引导
- 无数据引导
- 权限不足引导
- 搜索无结果引导
