#### [规范警告/Warning] 前端 `ApiResponse` 类型与后端不完全对齐

**前端**：[request.ts](file:///d:/vueprojects/RXAS400ADM/frontend/src/api/request.ts#L18-L22) 定义了 `ApiResponse<T>`，但后端 `ApiResponse` 是泛型类且 `data` 可能为 `null`。前端类型声明中 `data: T` 没有标注 `| null`，当 `ApiResponse.success()` 无参时 `data` 为 `null`，前端类型上无法体现。

```typescript
// 建议
export interface ApiResponse<T = unknown> {
  code: number;
  message: string;
  data: T | null; // 对齐后端无参 success()
}
```

> **AAA-Remark（2026-08-15 复核）**：✅ 真实存在——`request.ts` L18-L22 `data: T` 未标注 `| null`。⚠️ 响应拦截器已解包 `res.data`（返回值即业务 data），改 `data: T | null` 主要影响调用方类型收窄；建议与 §2.1 的 request.ts 重构**合并实施**（一次改动同时解决两处），并在 api 层解包处兜底 `?? null`。
