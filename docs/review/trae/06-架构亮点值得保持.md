# 六、架构亮点（值得保持）

1. **前后端统一响应格式**：`ApiResponse<T>` 在前后端均有对应类型定义，`code=0` 表示成功，错误码集中管理
2. **DTO/VO 三层隔离（用户模块）**：`UserDTO` → `SysUser` → `UserVO` 的转换链是其他模块应参照的模板
3. **`useTablePage` composable**：设计优秀，支持前端/后端分页、缓存、搜索、自适应高度，应作为团队 composable 开发标准
4. **Caffeine 权限缓存**：`PermissionService` 60s TTL 缓存 + 事件驱动失效，减少了 RBAC 打库
5. **安全实践**：密码强度校验、Token 混淆存储、IP 限流/黑白名单、SQL 注入防护测试、Webhook secret 脱敏
6. **请求去重**：`AbortController` + `pendingRequests` Map 防止列表页快速翻页竞态
7. **菜单并发去重**：`menusFetchPromise` 合并并发请求的巧妙设计
