# RXAS400ADM 部署到 AS400（IBM i）指南

- **编写日期**：2026-08-22
- **适用环境**：IBM i 7.4+ / 7.5+，Java 17（OpenJDK 或 IBM Semeru）
- **项目**：RXAS400ADM（Spring Boot 3.3 + Vue 3）

---

## 1. 架构概览

```
┌─────────────────────────────────────────────────┐
│                  IBM i (AS400)                    │
│                                                   │
│  ┌─────────────┐    ┌─────────────────────────┐  │
│  │  IFS 目录    │    │    QShell / PASE         │  │
│  │  /rxas400adm │    │                         │  │
│  │  ├─ jdk17/   │    │  java -jar rxas400adm.jar│ │
│  │  ├─ app/     │    │                         │  │
│  │  └─ logs/    │    │                         │  │
│  └─────────────┘    └─────────────────────────┘  │
│                                                   │
│  ┌─────────────────────────────────────────────┐  │
│  │           MySQL 8.0（本机或远程）             │  │
```

## 4. 部署到 IBM i

### 4.1 上传文件到 IFS

使用 FTP、SFTP 或 IBM i Access Client 上传：

```bash
# 方式 1：SFTP（推荐）
sftp user@your-as400-host
sftp> mkdir /rxas400adm
sftp> cd /rxas400adm
sftp> put -r rxas400adm-deploy/*
sftp> bye

# 方式 2：FTP
ftp your-as400-host
ftp> cd /rxas400adm
ftp> mput jdk17/*
ftp> mput app/*
ftp> mput conf/*
ftp> mput scripts/*
ftp> bye
```

### 4.2 在 IBM i 上配置权限

```bash
# 登录 QShell 或 PASE
system -i "STRQSH"

# 或通过 ACS → Run SQL Script 执行：
CALL QP2TERM

# 设置执行权限
chmod -R 755 /rxas400adm/jdk17/bin/
chmod -R 755 /rxas400adm/scripts/
chmod 644 /rxas400adm/app/*.jar
chmod 600 /rxas400adm/conf/.env
```

### 4.3 配置环境变量

编辑 `/rxas400adm/conf/.env`：

```bash
# 数据库配置
RXAS400_DB_HOST=localhost
RXAS400_DB_PORT=3306
RXAS400_DB_NAME=rxas400adm
MYSQL_ROOT_PASSWORD=your-strong-password

# JWT 密钥（必须 ≥32 字节随机值）
RXAS400_JWT_SECRET=your-random-secret-at-least-32-bytes-long

# 加密密钥（AS400 密码加密）
RXAS400_CRYPTO_KEY=$(openssl rand -base64 32)

# 时区
TZ=Asia/Shanghai
```

### 4.4 配置 application.yml

创建 `/rxas400adm/conf/application.yml`（覆盖默认配置）：

```yaml
spring:
  datasource:
    url: jdbc:mysql://${RXAS400_DB_HOST}:${RXAS400_DB_PORT}/${RXAS400_DB_NAME}?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: ${MYSQL_ROOT_PASSWORD}
  profiles:
    active: prod

server:
  port: 8080

rxas400:
  jwt:
    secret: ${RXAS400_JWT_SECRET}
  crypto:
    key: ${RXAS400_CRYPTO_KEY}
```

## 5. 启动与停止

### 5.1 启动脚本

创建 `/rxas400adm/scripts/start.sh`：

```bash
#!/bin/bash
# RXAS400ADM 启动脚本（IBM i QShell / PASE）

APP_DIR="/rxas400adm/app"
JDK_DIR="/rxas400adm/jdk17"
CONF_DIR="/rxas400adm/conf"
LOG_DIR="/rxas400adm/logs"
JAR_FILE="$APP_DIR/rxas400adm-app-1.0.0-SNAPSHOT.jar"
PID_FILE="$APP_DIR/app.pid"

# 加载环境变量
set -a
source "$CONF_DIR/.env"
set +a

# 检查是否已运行
if [ -f "$PID_FILE" ]; then
    PID=$(cat "$PID_FILE")
    if kill -0 "$PID" 2>/dev/null; then
        echo "RXAS400ADM 已在运行 (PID: $PID)"
        exit 1
    fi
fi

# 创建日志目录
mkdir -p "$LOG_DIR"

# 启动
echo "启动 RXAS400ADM..."
nohup "$JDK_DIR/bin/java" \
    -jar "$JAR_FILE" \
    --spring.config.additional-location="$CONF_DIR/application.yml" \
    --spring.profiles.active=prod \
    -Dfile.encoding=UTF-8 \
    -Xms512m -Xmx1024m \
    > "$LOG_DIR/rxas400adm.out" 2>&1 &

echo $! > "$PID_FILE"
echo "RXAS400ADM 已启动 (PID: $!)"
echo "日志：tail -f $LOG_DIR/rxas400adm.out"
```

### 5.2 停止脚本

创建 `/rxas400adm/scripts/stop.sh`：

```bash
#!/bin/bash
APP_DIR="/rxas400adm/app"
PID_FILE="$APP_DIR/app.pid"

if [ ! -f "$PID_FILE" ]; then
    echo "RXAS400ADM 未运行"
    exit 0
fi

PID=$(cat "$PID_FILE")
if kill -0 "$PID" 2>/dev/null; then
    echo "停止 RXAS400ADM (PID: $PID)..."
    kill "$PID"
    # 等待进程退出
    for i in $(seq 1 30); do
        if ! kill -0 "$PID" 2>/dev/null; then
            echo "已停止"
            rm -f "$PID_FILE"
            exit 0
        fi
        sleep 1
    done
    # 强制停止
    echo "强制停止..."
    kill -9 "$PID"
    rm -f "$PID_FILE"
else
    echo "进程 $PID 不存在，清理 PID 文件"
    rm -f "$PID_FILE"
fi
```

### 5.3 状态检查脚本

创建 `/rxas400adm/scripts/status.sh`：

```bash
#!/bin/bash
APP_DIR="/rxas400adm/app"
PID_FILE="$APP_DIR/app.pid"

if [ ! -f "$PID_FILE" ]; then
    echo "RXAS400ADM: 未运行"
    exit 1
fi

PID=$(cat "$PID_FILE")
if kill -0 "$PID" 2>/dev/null; then
    echo "RXAS400ADM: 运行中 (PID: $PID)"
    # 检查 HTTP 端口
    if curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/api/v1/auth/login 2>/dev/null | grep -q "401\|405"; then
        echo "HTTP 端口: 正常 (8080)"
    else
        echo "HTTP 端口: 异常"
    fi
else
    echo "RXAS400ADM: 进程已退出 (PID: $PID)"
    rm -f "$PID_FILE"
fi
```

## 6. 配置 systemd 服务（可选）

如果 IBM i 支持 systemd（7.4+），可以创建服务文件：

```bash
# /etc/systemd/system/rxas400adm.service
[Unit]
Description=RXAS400ADM AS400 Management Platform
After=network.target mysql.service

[Service]
Type=forking
ExecStart=/rxas400adm/scripts/start.sh
ExecStop=/rxas400adm/scripts/stop.sh
PIDFile=/rxas400adm/app/app.pid
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启用服务
systemctl daemon-reload
systemctl enable rxas400adm
systemctl start rxas400adm

# 查看状态
systemctl status rxas400adm
```

## 9. 常见问题

### Q: Java 找不到？

```bash
# 检查 JAVA_HOME
export JAVA_HOME=/rxas400adm/jdk17
export PATH=$JAVA_HOME/bin:$PATH
java -version
```

### Q: 端口被占用？

```bash
# 查找占用 8080 的进程
netstat -an | grep 8080
# 或
lsof -i :8080
```

### Q: 数据库连接失败？

```bash
# 检查 MySQL 是否运行
system -i "WRKACTJOB SBS(QZDASOINIT)"

# 检查 .env 配置
cat /rxas400adm/conf/.env
```

### Q: 日志在哪里？

```bash
tail -f /rxas400adm/logs/rxas400adm.out
```

### Q: 如何升级？

```bash
# 1. 停止服务
./stop.sh

# 2. 备份旧 JAR
cp /rxas400adm/app/rxas400adm-app-*.jar /rxas400adm/app/backup/

# 3. 上传新 JAR
# （通过 SFTP 上传新版本）

# 4. 启动服务
./start.sh
```

## 10. 安全注意事项

1. **JWT 密钥**：必须设置强随机值（≥32 字节），不要使用默认值
2. **数据库密码**：使用强密码，不要硬编码
3. **HTTPS**：生产环境建议在前端加 Nginx 反向代理 + SSL
4. **防火墙**：仅开放必要端口（8080 应用、3306 数据库仅本机）
5. **.env 文件**：权限设为 600，仅 owner 可读
6. **日志**：定期清理，避免磁盘占满
