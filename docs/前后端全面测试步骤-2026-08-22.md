# RXAS400ADM 前后端全面测试步骤

- **编写日期**：2026-08-22
- **覆盖范围**：登录认证 → 总览仪表盘 → AS400 运维全模块 → 系统管理 → 404 兜底
- **前置条件**：后端已启动（mock 模式）、前端 dev server 运行、MySQL 容器已启动

---

## 0. 环境准备

### 启动命令

```bash
# 后端（mock 模式，无需真实 IBM i）
cd backend && java -jar rxas400adm-app/target/rxas400adm-app-1.0.0-SNAPSHOT.jar \
  --spring.datasource.password=root --spring.profiles.active=mock

# 前端
cd frontend && npm run dev
```

### 验证后端就绪

```bash
curl -s http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
# 期望：返回 {"code":0,"data":{"token":"...","username":"admin",...}}
```

## 1. 登录认证模块

### 1.1 登录页访问

| 步骤 | 前端操作 | 目的 | 后端链路 | 涉及表 |
|---|---|---|---|---|
| 1 | 浏览器打开 `http://localhost:5173` | 未登录自动跳转 /login | `router.beforeEach` → 检查 `userStore.isLoggedIn` → 重定向 `/login` | — |
| 2 | 观察登录表单 | 验证 i18n 中英文切换、表单预填（admin/admin123） | — | — |

### 1.2 平台登录（admin/admin123）

> **注意**：平台登录验证本地 MySQL `rx_user` 表，**不检查 AS400**。与 AS400 账号登录（1.6 节）是两条独立链路。

| 步骤 | 前端操作 | 目的 | 后端链路 | 涉及表 |
|---|---|---|---|---|
| 3 | 输入用户名 `admin`，密码 `admin123`，点击「登录」 | 触发 POST `/api/v1/auth/login` | `AuthController.login()` → `userService.getByUsername()` → `passwordEncoder.matches()` 验证本地密码 | `rx_user`（查询用户+密码比对）、`rx_user_role`（角色关联）、`rx_role`（角色）、`rx_permission`（权限码） |
| 4 | 登录成功后观察 | 验证跳转到 `/dashboard`，顶栏显示用户名，左侧菜单加载 | `GET /api/v1/auth/menu` → `UserMenuService.buildMenuTree()` → 按用户角色过滤菜单 | `rx_menu`（菜单树）、`rx_user_menu`（用户菜单授权）、`rx_role_menu`（角色菜单关联） |
| 5 | 观察浏览器 localStorage | 验证 `token`、`tags` 已持久化 | `request.ts` 拦截器自动附加 `Authorization: Bearer <token>` | `rx_token_blacklist`（登出时写入） |

### 1.3 错误登录

| 步骤 | 前端操作 | 目的 | 后端链路 | 涉及表 |
|---|---|---|---|---|
| 6 | 输入错误密码，点击「登录」 | 验证错误提示 | `AuthController.login()` → `BusinessException(10001)` | `rx_login_attempt`（记录失败尝试） |

### 1.6 AS400 账号登录（独立链路）

> **与平台登录的区别**：AS400 登录将凭据委托给 IBM i 认证（mock 模式走 MockAS400Client），成功后自动创建/更新本地用户记录。需要选择服务器。

| 步骤 | 前端操作 | 目的 | 后端链路 | 涉及表 |
|---|---|---|---|---|
| 11 | 在登录页切换到「AS400 登录」模式，选择服务器，输入 AS400 用户名/密码 | 触发 POST `/api/v1/auth/as400-login` | `AuthController.as400Login()` → `As400LoginService.login()` → `client.authenticate()` 验证 AS400 凭据 | `rx_ibmi_system`（获取服务器连接信息）、`rx_user`（自动创建/更新本地用户）、`rx_user_role`（角色关联）、`rx_login_attempt`（登录审计） |
| 12 | AS400 登录成功 | 验证自动创建本地用户 + 跳转 | `As400LoginService.login()` → 首次登录自动创建用户（login_source='AS400'）+ 分配 VIEWER 角色 | `rx_user.login_source='AS400'`、`rx_user_role` |
| 13 | 使用已存在的 AS400 账号再次登录 | 验证不重复创建用户 | `userService.getByUsername()` → 用户已存在，直接返回 token | `rx_user`（查询已有用户） |
