## H2: 验证Flyway DB2兼容性

### 2.1 评估结论

**推荐方案**：使用 `docs/init_rxadmin.sql` 替代 Flyway

**原因**：
1. V1~V44 迁移文件使用 MySQL 语法（AUTO_INCREMENT、ENGINE=InnoDB、DATETIME等）
2. 改写为 DB2 for i 语法工作量大（8-16小时）
3. `init_rxadmin.sql` 已包含完整的建表+数据初始化（1229行）
4. 生产环境表结构稳定后不再频繁变更

### 2.2 使用 init_rxadmin.sql 的配置

```yaml
# application-db2.yml 中禁用 Flyway
spring:
  flyway:
    enabled: false
```

### 2.3 如果坚持使用 Flyway

需要修改迁移文件中的 MySQL 语法：

| MySQL 语法 | DB2 for i 语法 |
|---|---|
| `AUTO_INCREMENT` | `GENERATED ALWAYS AS IDENTITY` |
| `ENGINE=InnoDB` | 删除（DB2 无引擎概念） |
| `DEFAULT CHARSET=utf8mb4` | 删除（DB2 使用 CCSID） |
| `DATETIME` | `TIMESTAMP` |
| `TEXT` | `CLOB` |
| `TINYINT` | `SMALLINT` |
| `IFNULL(a, b)` | `COALESCE(a, b)` |
| `NOW()` | `CURRENT_TIMESTAMP` |
| `GROUP_CONCAT(...)` | `LISTAGG(...)` |
| `LIMIT n OFFSET m` | `FETCH FIRST n ROWS ONLY OFFSET m` |

### 2.4 示例迁移文件改写

```sql
-- 原 MySQL 版本（V1__init.sql）
CREATE TABLE rx_user (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT,
    username     VARCHAR(50)  NOT NULL UNIQUE,
    password     VARCHAR(255) NOT NULL,
    created_time DATETIME     DEFAULT CURRENT_TIMESTAMP
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4;

-- 改写为 DB2 for i
CREATE TABLE rx_user (
    id           BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    username     VARCHAR(50)  NOT NULL UNIQUE,
    password     VARCHAR(255) NOT NULL,
    created_time TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
);
```

## H3: 创建IBM i部署脚本

### 3.1 start.sh 启动脚本

```bash
#!/bin/sh
# ============================================================
# RXAS400ADM 启动脚本（US400CND）
# 路径：/QOpenSys/rxas400/start.sh
# ============================================================

# JDK 路径（项目目录内的 OpenJDK 17）
JAVA_HOME=/QOpenSys/rxas400/jdk17
PATH=$JAVA_HOME/bin:$PATH

# 项目目录
APP_HOME=/QOpenSys/rxas400
JAR=$APP_HOME/rxas400adm-app-1.0.0-SNAPSHOT.jar
LOG_DIR=$APP_HOME/logs
PID_FILE=$APP_HOME/rxas400adm.pid

# 环境变量（生产必须设置）
export RXAS400_JWT_SECRET=${RXAS400_JWT_SECRET:-$(openssl rand -base64 32)}
export RXAS400_CRYPTO_KEY=${RXAS400_CRYPTO_KEY:-$(openssl rand -base64 32)}
export RXAS400_IBMI_HOST=${RXAS400_IBMI_HOST:-localhost}
export RXAS400_IBMI_USER=${RXAS400_IBMI_USER:-RXAS400}
export RXAS400_IBMI_PASSWORD=${RXAS400_IBMI_PASSWORD}
export RXAS400_IFS_DOC_ROOT=${RXAS400_IFS_DOC_ROOT:-/QOpenSys/rxas400/document}
export RXAS400_PORT=${RXAS400_PORT:-8080}
export RXAS400_LOG_DIR=$LOG_DIR

# 创建日志目录
mkdir -p $LOG_DIR

# 停止旧进程
if [ -f $PID_FILE ]; then
    OLD_PID=$(cat $PID_FILE)
    if kill -0 $OLD_PID 2>/dev/null; then
        echo "Stopping old process $OLD_PID..."
        kill $OLD_PID
        sleep 5
        if kill -0 $OLD_PID 2>/dev/null; then
            echo "Force killing $OLD_PID..."
            kill -9 $OLD_PID
        fi
    fi
    rm -f $PID_FILE
fi

# 启动应用
echo "Starting rxas400adm..."
nohup java \
    -Xms256m \
    -Xmx1024m \
    -Dfile.encoding=UTF-8 \
    -jar $JAR \
    --spring.profiles.active=prod,db2 \
    --server.port=$RXAS400_PORT \
    > $LOG_DIR/startup.log 2>&1 &

echo $! > $PID_FILE
echo "rxas400adm started, PID=$(cat $PID_FILE)"
echo "Log file: $LOG_DIR/startup.log"
echo "API URL: http://localhost:$RXAS400_PORT/api/v1"
```

## M1: DB2 for i迁移文件改写

### 1.1 MySQL → DB2 语法对照表

| MySQL | DB2 for i | 说明 |
|---|---|---|
| `AUTO_INCREMENT` | `GENERATED ALWAYS AS IDENTITY` | 自增主键 |
| `ENGINE=InnoDB` | 删除 | DB2 无引擎概念 |
| `DEFAULT CHARSET=utf8mb4` | 删除 | DB2 使用 CCSID |
| `DATETIME` | `TIMESTAMP` | 日期时间 |
| `TEXT` | `CLOB` | 大文本 |
| `TINYINT` | `SMALLINT` | 小整数 |
| `IFNULL(a, b)` | `COALESCE(a, b)` | 空值处理 |
| `NOW()` | `CURRENT_TIMESTAMP` | 当前时间 |
| `GROUP_CONCAT(...)` | `LISTAGG(... ON OVERFLOW TRUNCATE)` | 列聚合 |
| `LIMIT n` | `FETCH FIRST n ROWS ONLY` | 分页 |
| `LIMIT n OFFSET m` | `OFFSET m ROWS FETCH NEXT n ROWS ONLY` | 偏移分页 |
| `INSERT IGNORE` | `MERGE INTO` 或 `INSERT` + 异常处理 | 忽略重复 |
| `ON DUPLICATE KEY UPDATE` | `MERGE INTO` | 更新或插入 |
| `BACKtick` | 无（使用双引号） | 标识符引用 |
| `ENUM('a','b')` | `VARCHAR` + `CHECK` | 枚举类型 |

### 1.2 迁移文件改写示例

#### V1__init.sql 示例

```sql
-- 原 MySQL 版本
CREATE TABLE rx_user (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT,
    username     VARCHAR(50)  NOT NULL UNIQUE,
    password     VARCHAR(255) NOT NULL,
    email        VARCHAR(100),
    status       VARCHAR(20)  DEFAULT 'ACTIVE',
    created_by   VARCHAR(50),
```

### 1.3 MyBatis Plus 分页适配

DB2 for i 的分页语法与 MySQL 不同，MyBatis Plus 已内置适配：

```java
// 无需修改代码，MyBatis Plus 会自动适配
Page<User> page = new Page<>(current, size);
userMapper.selectPage(page, wrapper);
```

如果自定义 SQL，需要手动适配：

```xml
<!-- MySQL -->
<select id="selectList">
    SELECT * FROM rx_user
    LIMIT #{size} OFFSET #{offset}
</select>

<!-- DB2 for i -->
<select id="selectList">
    SELECT * FROM rx_user
    OFFSET #{offset} ROWS FETCH NEXT #{size} ROWS ONLY
</select>
```

### 2.2 语法转换脚本

```bash
#!/bin/bash
# convert_mysql_to_db2.sh
# 将 MySQL 导出转换为 DB2 for i 兼容格式

INPUT_FILE=$1
OUTPUT_FILE="${INPUT_FILE%.sql}_db2.sql"

# 转换函数
convert() {
    sed \
        -e 's/AUTO_INCREMENT/GENERATED ALWAYS AS IDENTITY/g' \
        -e 's/ENGINE=InnoDB//g' \
        -e 's/DEFAULT CHARSET=utf8mb4//g' \
        -e 's/DATETIME/TIMESTAMP/g' \
        -e 's/IFNULL/COALESCE/g' \
        -e 's/NOW()/CURRENT_TIMESTAMP/g' \
        -e "s/\\\`/'/g" \
        -e 's/INSERT INTO/INSERT INTO/g' \
        -e 's/),(/); INSERT INTO /g' \
        "$INPUT_FILE" > "$OUTPUT_FILE"
}

convert
echo "Converted: $OUTPUT_FILE"
```

## M3: 默认密码强制修改

### 3.1 数据库变更

```sql
-- 新增密码修改标记字段
ALTER TABLE RX_USER ADD COLUMN PASSWORD_CHANGED SMALLINT DEFAULT 0 NOT NULL;

-- 更新现有用户（admin 除外）
UPDATE RX_USER SET PASSWORD_CHANGED = 0 WHERE USERNAME != 'admin';

-- 标记 admin 为未修改（首次登录需强制修改）
UPDATE RX_USER SET PASSWORD_CHANGED = 0 WHERE USERNAME = 'admin';
```

### 3.2 后端实现

```java
// UserVO.java 添加字段
public class UserVO {
    // ... 现有字段
    private Boolean passwordChanged;
}

// UserService.java 添加方法
public interface IUserService {
    // ... 现有方法
    boolean needPasswordChange(String username);
    void changePassword(String username, String oldPassword, String newPassword);
}

// UserServiceImpl.java 实现
@Override
public boolean needPasswordChange(String username) {
    SysUser user = userMapper.selectByUsername(username);
    return user != null && !Boolean.TRUE.equals(user.getPasswordChanged());
}

@Override
public void changePassword(String username, String oldPassword, String newPassword) {
    SysUser user = userMapper.selectByUsername(username);
    if (user == null) {
        throw new BusinessException(ErrorCode.USER_NOT_FOUND);
    }
    
    // 验证旧密码
    if (!passwordEncoder.matches(oldPassword, user.getPassword())) {
        throw new BusinessException(ErrorCode.PASSWORD_ERROR);
    }
    
    // 更新密码
    user.setPassword(passwordEncoder.encode(newPassword));
    user.setPasswordChanged(true);
    userMapper.updateById(user);
    
    // 记录审计日志
    auditLogService.log(AuditLog.builder()
        .action("PASSWORD_CHANGE")
        .module("USER")
        .target(username)
        .build());
```

### 4.2 Token 服务实现

```java
// JwtTokenService.java
@Service
@RequiredArgsConstructor
public class JwtTokenService {
    
    private final JwtEncoder jwtEncoder;
    private final JwtDecoder jwtDecoder;
    
    @Value("${rxas400.jwt.expire-ms}")
    private long accessTokenExpireMs;
    
    @Value("${rxas400.jwt.refresh-expire-ms}")
    private long refreshTokenExpireMs;
    
    /**
     * 生成 Access Token
     */
    public String generateAccessToken(UserDetails userDetails) {
        Instant now = Instant.now();
        String scope = userDetails.getAuthorities().stream()
            .map(GrantedAuthority::getAuthority)
            .collect(Collectors.joining(" "));
        
        JwtClaimsSet claims = JwtClaimsSet.builder()
            .issuer("rxas400adm")
            .issuedAt(now)
            .expiresAt(now.plusMillis(accessTokenExpireMs))
            .subject(userDetails.getUsername())
            .claim("scope", scope)
            .claim("token_type", "access")
            .build();
        
        return jwtEncoder.encode(JwtEncoderParameters.from(claims)).getTokenValue();
    }
    
    /**
     * 生成 Refresh Token
     */
    public String generateRefreshToken(UserDetails userDetails) {
        Instant now = Instant.now();
        
        JwtClaimsSet claims = JwtClaimsSet.builder()
            .issuer("rxas400adm")
            .issuedAt(now)
            .expiresAt(now.plusMillis(refreshTokenExpireMs))
            .subject(userDetails.getUsername())
            .claim("token_type", "refresh")
            .build();
        
        return jwtEncoder.encode(JwtEncoderParameters.from(claims)).getTokenValue();
    }
    
    /**
     * 刷新 Access Token
     */
    public TokenResponse refreshToken(String refreshToken) {
        try {
            Jwt<?> jwt = jwtDecoder.decode(refreshToken);
            String username = jwt.getSubject();
            String tokenType = jwt.getClaimAsString("token_type");
            
            if (!"refresh".equals(tokenType)) {
                throw new InvalidTokenException("Invalid refresh token");
            }
            
            // 验证 refresh token 是否在黑名单中
            // ... 
            
            // 生成新的 access token
            UserDetails userDetails = userDetailsService.loadUserByUsername(username);
            String newAccessToken = generateAccessToken(userDetails);
            String newRefreshToken = generateRefreshToken(userDetails);
            
            return TokenResponse.builder()
                .accessToken(newAccessToken)
                .refreshToken(newRefreshToken)
                .build();
                
        } catch (Exception e) {
            throw new InvalidTokenException("Invalid refresh token");
        }
    }
}

// TokenResponse.java

@Builder

    private String accessToken;
    private String refreshToken;
    private String tokenType;
    private long expiresIn;
}
```

### 4.4 前端实现

```typescript
// api/auth.ts
export interface TokenResponse {
  accessToken: string
  refreshToken: string
  tokenType: string
  expiresIn: number
}

export const login = (data: LoginCredentials) =>
  request.post<TokenResponse>('/auth/login', data)

export const refreshToken = (refreshToken: string) =>
  request.post<TokenResponse>('/auth/refresh', { refreshToken })

// stores/user.ts
export const useUserStore = defineStore('user', {
  state: () => ({
    accessToken: '',
    refreshToken: '',
    tokenExpireTime: 0
  }),
  
  actions: {
    async login(credentials: LoginCredentials) {
      const { data } = await login(credentials)
      this.accessToken = data.accessToken
      this.refreshToken = data.refreshToken
      this.tokenExpireTime = Date.now() + data.expiresIn * 1000
      
      // 设置定时刷新
      this.scheduleTokenRefresh(data.expiresIn)
    },
    
    scheduleTokenRefresh(expiresIn: number) {
      // 在过期前 5 分钟刷新
      const refreshTime = (expiresIn - 300) * 1000
      setTimeout(() => {
        this.refreshAccessToken()
      }, refreshTime)
    },
    
    async refreshAccessToken() {
      try {
        const { data } = await refreshToken(this.refreshToken)
        this.accessToken = data.accessToken
        this.refreshToken = data.refreshToken
        this.tokenExpireTime = Date.now() + data.expiresIn * 1000
        
        this.scheduleTokenRefresh(data.expiresIn)
      } catch (error) {
        this.logout()
      }
    },
    
    logout() {
      this.accessToken = ''
      this.refreshToken = ''
      this.tokenExpireTime = 0
      router.push('/login')
    }
  }
})

// utils/request.ts
instance.interceptors.request.use((config) => {
  const userStore = useUserStore()
  
  // 检查 token 是否过期
  if (Date.now() > userStore.tokenExpireTime) {
    userStore.refreshAccessToken()
  }
  
  config.headers.Authorization = `Bearer ${userStore.accessToken}`
  return config
})
```
