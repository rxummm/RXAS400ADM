## 一、IBM i 环境准备

### 1.1 创建运行用户（建议非 QSECOFR）

- [ ] `CRTUSRPRF RXAS400 Password(xxxx) SPCAUT(*NONE) INLPGM(*NONE)`
- [ ] 授予必要权限：
  ```cl
  GRTOBJAUT OBJ(RXADMIN) OBJTYPE(*LIB) USER(RXAS400) AUT(*CHANGE)
  GRTOBJAUT OBJ(QSYS/QShell) OBJTYPE(*PGM) USER(RXAS400) AUT(*USE)
  ```
- [ ] 创建 IFS 目录：
  ```bash
  mkdir -p /QOpenSys/rxas400
  chown RXAS400:RXAS400 /QOpenSys/rxas400
  ```

### 1.2 安装 OpenJDK 17

- [ ] 下载 IBM Semeru OpenJDK 17 for ppc64-ibm-i：
  ```
  https://developer.ibm.com/languages/java/semeru-runtimes/downloads/
  选择: Java 17 LTS / IBM Semeru Runtime / ppc64-ibm-i
  ```
- [ ] 解压到项目目录：
  ```bash
  cd /QOpenSys/rxas400
  tar xzf openj9-17.tar.gz
  ```
- [ ] 验证：
  ```bash
  /QOpenSys/rxas400/jdk-17/bin/java -version
  # 输出: openj9-17.x.x (Java 17)
  ```
- [ ] 设置环境变量（推荐写入启动脚本）：
  ```bash
  export JAVA_HOME=/QOpenSys/rxas400/jdk-17
  export PATH=$JAVA_HOME/bin:$PATH
  ```

### 1.3 准备 MySQL / DB2 for i

**方案 A：使用 DB2 for i（推荐，生产方案）**

- [ ] 创建 Library：
  ```sql
  CREATE LIBRARY RXADMIN
  ```
- [ ] 执行初始化 SQL：
  ```bash
  # 通过 ACS 上传 init_rxadmin.sql 到 /QOpenSys/rxas400/
  db2 -f /QOpenSys/rxas400/init_rxadmin.sql
  ```
- [ ] 导入行政区划数据：
  ```bash
  # 上传 region_data.csv 到 /QOpenSys/rxas400/
  IMPORT FROM /QOpenSys/rxas400/region_data.csv OF DEL INSERT INTO RXADMIN.RX_REGION
  ```
- [ ] 验证：
  ```sql

  SELECT COUNT(*) FROM RXADMIN.RX_ROLE;       -- 期望 4
  ```

## 二、应用部署

### 2.1 上传文件

- [ ] 上传 jar 到 `/QOpenSys/rxas400/`
  ```bash
  scp rxas400adm-app-1.0.0-SNAPSHOT.jar RXAS400@US400CND:/QOpenSys/rxas400/
  ```
- [ ] 上传前端构建产物到 Web 服务器（Nginx/Apache）
  ```bash
  scp -r frontend/dist/* RXAS400@US400CND:/QOpenSys/rxas400/web/
  ```

### 2.2 配置环境变量

- [ ] 创建 env 文件 `/QOpenSys/rxas400/env`：
  ```bash
  # 必填
  export RXAS400_JWT_SECRET="<32字节以上随机值>"
  
  # DB2 for i 连接（方案 A）
  export RXAS400_DB_URL="jdbc:as400://localhost/RXADMIN"
  export RXAS400_DB_USERNAME="RXAS400"
  export RXAS400_DB_PASSWORD="<密码>"
  
  # MySQL 连接（方案 B）
  # export RXAS400_DB_URL="jdbc:mysql://localhost:3306/rxas400adm"
  # export RXAS400_DB_USERNAME="root"
  # export RXAS400_DB_PASSWORD="<密码>"
  
  # IBM i 连接（JTOpen）
  export RXAS400_AS400_HOST="localhost"
  export RXAS400_AS400_USER="QSECOFR"
  export RXAS400_AS400_PASSWORD="<密码>"
  
  # 可选
  export RXAS400_IFS_DOC_ROOT="/QOpenSys/rxas400/document"
  export RXAS400_WEBSOCKET_URL="ws://localhost:8080/ws"
  ```
- [ ] 设置文件权限：`chmod 600 /QOpenSys/rxas400/env`
- [ ] ⚠️ **RXAS400_JWT_SECRET 必须 32 字节以上**，否则 StartupGuard 拒绝启动

### 2.3 创建启动脚本

- [ ] 创建 `/QOpenSys/rxas400/start.sh`：
  ```bash
  #!/bin/bash
  cd /QOpenSys/rxas400
  source env
  
  export JAVA_HOME=/QOpenSys/rxas400/jdk-17
  export PATH=$JAVA_HOME/bin:$PATH
  
  nohup java \
    -Xms256m -Xmx1024m \
    -Dfile.encoding=UTF-8 \
    -Dspring.profiles.active=prod \
    -jar rxas400adm-app-1.0.0-SNAPSHOT.jar \
    > logs/app.log 2>&1 &
  
  echo "PID: $!" > app.pid
  echo "Started at $(date)" >> logs/startup.log
  ```
- [ ] 创建停止脚本 `/QOpenSys/rxas400/stop.sh`：
  ```bash
  #!/bin/bash
  if [ -f app.pid ]; then
    kill $(cat app.pid) 2>/dev/null
    rm -f app.pid
    echo "Stopped at $(date)" >> logs/startup.log
  fi
  ```
- [ ] 设置执行权限：`chmod +x /QOpenSys/rxas400/start.sh /QOpenSys/rxas400/stop.sh`

### 2.4 启动应用

- [ ] 创建日志目录：`mkdir -p /QOpenSys/rxas400/logs`
- [ ] 启动：`/QOpenSys/rxas400/start.sh`
- [ ] 等待启动完成（约 30-60 秒）
- [ ] 检查日志：
  ```bash
  tail -50 /QOpenSys/rxas400/logs/app.log
  # 确认看到: "Started Rxas400admApplication in X seconds"
  ```
