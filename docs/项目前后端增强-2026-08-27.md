### 7.5 SQL 注入审计结论

全库 mapper XML 扫描：**0 处 `${}` 用法**，所有 MyBatis Plus 查询均使用 `#{}` 参数化绑定。CDI 客户端 CL 命令均为硬编码 SQL 字符串，无用户输入拼接。**结论：当前无 SQL 注入风险。**

### 7.6 CL 命令注入风险评估（已知限制）

`DataAreaClient`/`SysvalClient` 的 CL 命令通过 `QCMDEXC` 执行，参数值直接嵌入命令字符串。当前均为内部系统调用且参数类型受限（系统值名/数据区域名），**短期风险可控**。若未来开放用户自定义系统值名，需改为白名单校验。

### 15.6 控制器层规约修复（§2.1.1）

邮件功能初始实现时，`EmailConfigController`、`EmailGroupController`、`EmailLogController` 直接注入 Mapper 并使用 `LambdaQueryWrapper`，违反 §2.1.1「Controller 不得注入 Mapper、不得 `new QueryWrapper`/`new LambdaQueryWrapper`」。

|------------|--------|--------|

| `EmailGroupController` | 注入 `groupMapper` + `recipientMapper`，8 个方法全部使用 LambdaQueryWrapper | 仅注入 `IEmailGroupService`，所有逻辑委托 |
| `EmailLogController` | 注入 `emailLogMapper`，`page()`/`detail()` 使用 LambdaQueryWrapper | 仅注入 `IEmailLogService`，所有逻辑委托 |

新增 Service 接口/实现：
- `IEmailGroupService` + `EmailGroupService`（8 个方法）
- `IEmailLogService` + `EmailLogService`（2 个方法）
