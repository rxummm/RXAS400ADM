7 个 BPCS Service 中重复定义的 `strEq`/`strContains`/`pickStr`/`intVal`/`intOrNull`/`decOrNull`/`dblOrNull`/`dateStr` 方法已统一提取到 `BpcsRowUtil` 工具类，消除约 150 行重复代码。

| `strEq(row, key, val)` | 大小写不敏感字符串相等 | 7 个 |

| `pickStr(row, key/keys)` | 取字符串值或 null（支持 varargs） | 7 个 |
| `intVal(row, key)` | 取 int 值或 0 | 5 个 |
| `intOrNull(row, key/keys)` | 取 Integer 或 null（支持 varargs） | 5 个 |
| `decOrNull(row, key/keys)` | 取 BigDecimal 或 null（支持 varargs） | 7 个 |
| `dblOrNull(row, key)` | 取 Double 或 null | 1 个 |
| `dateStr(row, key/keys)` | CYYMMDD 转日期字符串（支持 varargs） | 5 个 |

## 三、IBM i 原生功能增强

### 3.1 假脱机文件下载/删除（P0）
- `GET /spool/content`（DSPSPLF 流式下载）+ `POST /spool/delete`（DLTSPLF + @OperateLog）
- 前端 Spool Tab 操作列：下载 + 删除（二次确认）

### 3.2 系统值批量修改（P2）
- `POST /system-values/batch` 批量修改端点
- 前端批量编辑模式：勾选多个系统值 → 统一修改预览 → 确认提交

### 3.3 PF 表统计增强（P3）
- `GET /pf/stats` 返回 recordCount/storageSize/indexCount/indexNames/memberCount
- 前端统计面板：记录数/存储大小/索引数/成员数 + 索引名称标签

### 3.4 数据区域 Data Area 模块（P1，全新）
- 完整 CRUD：`DataAreaClient` + `JTOpenDataAreaClient` + `MockDataAreaClient`
- `DataAreaController` + 前端页面 + 菜单权限 + `V62__data_area_menu.sql`

### 3.5 用户态管理增强（P1）
- `AuthClient` 新增 `listUserProfiles()` + `switchUser()`
- `UserProfileController`：`GET /user-profiles` + `POST /user-profiles/switch`
- 前端页面 `views/system/userProfiles/index.vue`：用户列表 + 切换弹窗

### 3.6 日志管理增强（P2）
- `JobClient` 新增 `historyLog()`（QSYS2.HISTORY_LOG_INFO）
- `GET /jobs/history-log`：按作业名/日期范围查询历史日志
- 前端 API `fetchHistoryLog()`
